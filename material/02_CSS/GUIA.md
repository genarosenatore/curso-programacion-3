[Inicio](../INICIO.md) · [Roadmap](../ROADMAP.md) · [Ejemplos ejecutables](../EJEMPLOS.md)

## Para qué sirve

CSS define cómo se presenta el contenido HTML. Una misma estructura puede tener distintos colores, espacios y disposiciones. Antes de construir diseños completos, vamos a entender qué regla afecta a cada elemento y por qué.
