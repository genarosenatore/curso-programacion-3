# Unidad 14 · Spring Boot y API REST

[Inicio](../INICIO.md) · [Roadmap](../ROADMAP.md) · [Ejemplos ejecutables](../EJEMPLOS.md)

## Para qué sirve

Spring ayuda a organizar y conectar componentes de una aplicación. Spring Boot facilita su configuración y arranque. Una API REST expone operaciones a través de HTTP para que el frontend pueda pedir y modificar datos.
