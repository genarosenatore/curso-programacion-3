# Unidad 05 · Java desde cero y orientación a objetos

[Inicio](../INICIO.md) · [Roadmap](../ROADMAP.md) · [Ejemplos ejecutables](../EJEMPLOS.md)

## Para qué sirve

Java será el lenguaje de nuestro backend. Vamos a reutilizar las ideas de variables, decisiones y funciones, aprendiendo su sintaxis. Después representaremos elementos del problema mediante objetos: un producto puede tener nombre, precio y acciones relacionadas.

## Práctica de cierre

Crear clases con responsabilidades claras, instanciar objetos y explicar una interfaz y el manejo de una excepción.

Elegí un ejemplo de esta unidad, probalo con una entrada normal y un caso que no deba aceptarse o no tenga coincidencias, y explicá la decisión. Compará después con la consigna del campus que corresponda. La carpeta original conserva los documentos íntegros.
