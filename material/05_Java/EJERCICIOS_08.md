# Práctica 05.08 · Interfaces y polimorfismo

[Clase](CLASE_08.md) · [Soluciones separadas](SOLUCIONES_08.md)

## 1. Actividad guiada

Agregá una implementación de envío express que devuelva 100000 centavos.

1. Implementá Express con método public.
2. Construílo en una variable Envio.
3. Invocá el contrato sin un if por nombre de clase.

Anotá el resultado previsto antes de comprobarlo. La explicación del recorrido está en la clase y la solución de esta actividad está separada para consultar después del intento.

## 2. Para resolver por tu cuenta

Implementá Express y usalo desde una referencia Envio.

## 3. Combinar lo aprendido

Recorré Retiro, Domicilio y Express en un array y calculá sus costos. Explicá el tipo declarado de la variable frente al tipo concreto de cada objeto. ¿Por qué un if por nombre de clase duplica el contrato?

## Pistas graduales

Usá una pista por vez, después de intentar el ejercicio.

1. implements expresa el cumplimiento.
2. El método implementado debe ser public.
3. El consumidor llama la operación común.
