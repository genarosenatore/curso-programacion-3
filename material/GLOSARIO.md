# Glosario del curso

[Inicio](INICIO.md)

| Término | Significado en este curso |
|---|---|
| Algoritmo | Secuencia definida de pasos para resolver un problema. |
| Programa | Instrucciones escritas para que una computadora realice una tarea. |
| Dato | Valor con el que trabaja una solución. |
| Entrada | Datos que recibe el proceso. |
| Proceso | Operaciones que transforman o utilizan los datos. |
| Salida | Resultado que produce el proceso. |
| Sintaxis | Reglas para escribir instrucciones en un lenguaje. |
| Pseudocódigo | Descripción de pasos que permite pensar una solución sin usar una sintaxis ejecutable concreta. |
| Prueba de escritorio | Seguimiento manual de los pasos para comprobar lo que ocurre. |
| Error de lógica | Instrucción o decisión que produce un comportamiento distinto del que requiere el problema. |
| Navegador | Programa que interpreta y muestra páginas web. |
| Servidor | Sistema que recibe solicitudes y ofrece recursos o servicios. |
| HTTP | Reglas para intercambiar solicitudes y respuestas en la web. |
| HTTPS | HTTP protegido mediante cifrado del intercambio. |
| HTML | Lenguaje de marcado para describir contenido y estructura. |
| CSS | Lenguaje de estilos para definir presentación. |
| JavaScript | Lenguaje de programación que usaremos para lógica e interactividad. |
| Frontend | Parte de la aplicación con la que interactúa la persona en el navegador. |
| Backend | Parte que procesa solicitudes del lado del servidor. |
| Base de datos | Sistema para organizar y conservar información que se puede consultar. |

El glosario crecerá con las clases. Los términos de unidades futuras se definirán antes de usarlos en ejercicios.

## Términos para las siguientes unidades

| Término | Significado |
|---|---|
| Variable | Nombre asociado a un valor que utiliza el programa. |
| Función | Bloque de instrucciones que se puede invocar para una tarea. |
| Parámetro | Dato que una función declara recibir. |
| Argumento | Valor concreto enviado al invocar una función. |
| Retorno | Valor que una función entrega a quien la llamó. |
| Condición | Expresión que permite decidir según verdadero o falso. |
| Bucle | Repetición controlada de instrucciones. |
| Array | Secuencia de elementos accesibles por posición. |
| DOM | Representación de los elementos de una página que permite consultarlos y modificarlos. |
| Evento | Notificación de una interacción o cambio, como un clic. |
| Promesa | Objeto que representa el resultado futuro de una operación. |
| JSON | Formato de texto para intercambiar datos estructurados. |
| Compilador | Herramienta que transforma código y comprueba reglas del lenguaje. |
| Tipo | Descripción de los valores y operaciones que admite un dato. |
| Interfaz | Contrato que describe capacidades o estructura. |
| Clase | Definición de objetos con datos y comportamiento. |
| Objeto | Valor concreto con estado y comportamiento. |
| Encapsulación | Control del acceso al estado para conservar sus reglas. |
| Herencia | Relación por la que una clase amplía otra. |
| Polimorfismo | Uso de implementaciones distintas mediante un contrato común. |
| Excepción | Señal de una situación que altera el flujo normal. |
| Colección | Estructura que agrupa elementos. |
| List | Colección Java ordenada que admite repetidos. |
| Set | Colección Java que representa elementos únicos. |
| Map | Estructura Java que asocia claves con valores. |
| equals | Método que expresa igualdad lógica según las reglas del objeto. |
| hashCode | Valor usado por estructuras hash; objetos iguales deben tener el mismo valor. |
| DTO | Objeto que reúne los datos necesarios para transferir información. |
| Record | Forma de declarar un portador de datos Java con componentes definidos. |
| Genérico | Código parametrizado por tipos. |
| Reflection | Inspección de clases y miembros durante la ejecución. |
| Lambda | Expresión breve que implementa una interfaz funcional. |
| Stream | Secuencia de operaciones sobre elementos; no es una colección para almacenar. |
| SQL | Lenguaje para definir y consultar datos relacionales. |
| Clave primaria | Dato o conjunto de datos que identifica una fila. |
| Clave foránea | Dato que referencia una clave de otra tabla o de la misma tabla. |
| JOIN | Operación que combina filas según una relación. |
| Transacción | Conjunto de operaciones que se confirma o revierte como una unidad. |
| JPA | Especificación Java para persistencia de objetos y relaciones. |
| Entidad | Objeto persistente con identidad. |
| JPQL | Lenguaje de consultas sobre entidades y sus atributos. |
| Hibernate | Implementación de JPA usada en el proyecto Spring. |
| Repositorio | Componente que ofrece operaciones de acceso a datos. |
| Servicio | Componente que coordina reglas y operaciones de la aplicación. |
| Controlador | Componente que recibe solicitudes HTTP y construye respuestas. |
| Inyección de dependencias | Entrega de colaboradores necesarios al construir un componente. |
| Endpoint | Dirección y método HTTP que permiten una operación de la API. |
| Validación | Comprobación de que los datos respetan reglas. |
| Autorización | Decisión del servidor sobre qué acciones puede realizar una identidad. |
| Maven | Herramienta Java para configurar dependencias y construir el proyecto. |
