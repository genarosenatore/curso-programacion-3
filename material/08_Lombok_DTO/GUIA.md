## Para qué sirve

Lombok genera parte del código repetitivo de Java mediante anotaciones. Un DTO es un objeto que define los datos que trasladamos entre partes de una aplicación. Primero escribiremos ejemplos manuales para entender qué automatiza cada herramienta.
