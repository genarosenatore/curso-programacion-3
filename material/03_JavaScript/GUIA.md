## Para qué sirve

JavaScript permite calcular, tomar decisiones y responder a acciones. Un botón puede existir en HTML y verse bien con CSS; JavaScript define qué sucede al pulsarlo. Primero aprenderemos la lógica con ejemplos pequeños y después la conectaremos con la página.
