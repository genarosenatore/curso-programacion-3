## Para qué sirve

Guardar datos en una base permite recuperarlos después de cerrar el programa. En una base relacional organizamos datos en tablas y relacionamos sus filas mediante claves. Esta base facilitará entender las relaciones de JPA.

## Práctica de cierre

Dibujar un modelo sencillo, relacionar filas mediante claves y explicar una consulta y una transacción.

Elegí un ejemplo de esta unidad, probalo con una entrada normal y un caso que no deba aceptarse o no tenga coincidencias, y explicá la decisión. Compará después con la consigna del campus que corresponda. La carpeta original conserva los documentos íntegros.
