## 1. Razonamiento de la actividad guiada

Entrada: 800 pesos por unidad y cuatro unidades. Proceso: 800 × 4. Salida: 3200 pesos. HTML contiene campos y resultado; JavaScript realiza el cálculo. CSS organiza su presentación. La multiplicación representa sumar el precio cuatro veces.

## 2 y 3. Resolver y justificar las decisiones

El cálculo es 1200 × 3 = 3600 pesos: precio y cantidad entran, multiplicar es el proceso y 3600 es la salida. La suma produciría 1203, que no equivale al precio de tres unidades.

El navegador solicita libros; el backend consulta la base; devuelve la lista; el navegador la presenta. HTML estructura los títulos y la lista; CSS la hace legible; JavaScript inicia la petición y coloca los datos recibidos. El backend decide cómo acceder al almacenamiento. Si ya hay una copia local del catálogo, se puede mostrar esa copia sin conexión, pero puede estar desactualizada. Crear un préstamo confirmado requiere comunicarse con el servidor que controla disponibilidad.
