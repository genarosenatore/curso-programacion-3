# Práctica 04.08 · DOM tipado y consumo de APIs

[Clase](CLASE_08.md) · [Soluciones separadas](SOLUCIONES_08.md)

## 1. Actividad guiada

Definí una comprobación que acepte solo objetos con id:number y nombre:string.

1. Recibí el valor como unknown.
2. Comprobá objeto no null, propiedades y tipos.
3. Probá un objeto válido y dos formas inválidas.

Anotá el resultado previsto antes de comprobarlo. La explicación del recorrido está en la clase y la solución de esta actividad está separada para consultar después del intento.

## 2. Para resolver por tu cuenta

Prepará un input y comprobalo con instanceof antes de registrar input. Mostrá su texto en consola.

## 3. Combinar lo aprendido

Escribí esLibro para id entero positivo y titulo texto no vacío. Probá cuatro datos, incluyendo null y un id textual. ¿Por qué as no valida un JSON y por qué un predicado debe tener una implementación correcta?

## Pistas graduales

Usá una pista por vez, después de intentar el ejercicio.

1. Verificá objeto y no null antes de leer.
2. in permite comprobar las propiedades.
3. El predicado afirma solo lo que sus condiciones demostraron.
