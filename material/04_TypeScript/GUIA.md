## Para qué sirve

TypeScript permite expresar qué datos espera nuestro código y detectar muchos errores antes de ejecutarlo. Por ejemplo, podemos indicar que el precio de un producto debe ser un número. El navegador ejecutará el JavaScript obtenido a partir de ese código.
