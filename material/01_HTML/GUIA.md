## Para qué sirve

HTML describe qué contenido tiene una página y cómo se organiza. Pensá en el índice y las secciones de un libro: un título, un párrafo y una lista tienen funciones distintas. Vamos a usar etiquetas para expresar esas funciones.

## Práctica de cierre

Crear una página con estructura semántica, enlaces que funcionen y un formulario con etiquetas asociadas a sus campos.
