## Qué vas a aprender

Vamos a trabajar **práctica: página personal, registro y blog**. Al terminar deberías poder explicar el ejemplo, modificarlo según la práctica y detectar el error común indicado al final.

## Antes de empezar

Leé las clases anteriores en orden. Si una palabra o una operación todavía cuesta, podés volver usando «Clase anterior». El ejemplo de esta clase se concentra en una idea; no necesitás entender las unidades posteriores para seguirla.

## Explicación desde cero

Una práctica integradora une varios temas. Empezamos por los requisitos y los traducimos a una lista comprobable. La consigna de página personal usa encabezado, descripción, imagen, enlace y pie; las siguientes prácticas añaden registro y contenido de blog con tabla.

Separá la estructura del estilo: en esta unidad queremos que el contenido exista y tenga sentido. Podés reutilizar el documento base y cambiar solo las piezas necesarias. Antes de mirar la solución, recorré la página como usuario y comprobá todos los enlaces.

## Ejemplo

```html
<main>
  <h1>Mi página personal</h1>
  <p>Estoy aprendiendo desarrollo web.</p>
  <section><h2>Mis intereses</h2><ul><li>Programación</li></ul></section>
  <a href="registro.html">Abrir formulario de registro</a>
</main>
```

## Leamos el ejemplo paso a paso

Este fragmento se coloca dentro del body del documento base. registro.html debe existir al lado de index.html. Hacé una tabla de requisitos: elemento esperado, archivo donde está y cómo comprobarlo. Una página que se ve bien puede tener un enlace roto o un campo sin etiqueta; la revisión debe incluir comportamiento y estructura.

Antes de continuar, explicá con tus palabras la función de las instrucciones principales. Compará la salida o comportamiento descrito con lo que observás al probarlo. Si no coincide, revisá entrada, contexto de ejecución y resultado antes de cambiar el código.
