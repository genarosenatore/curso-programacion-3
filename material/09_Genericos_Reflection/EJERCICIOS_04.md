# Práctica 09.04 · Class y metadatos de una clase

[Clase](CLASE_04.md) · [Soluciones separadas](SOLUCIONES_04.md)

## 1. Actividad guiada

Inspeccioná una clase propia Cliente y mostrale su nombre y sus campos declarados.

1. Obtén Cliente.class y sus campos declarados.
2. Mostrá nombre y tipo de cada descriptor.
3. Diferenciá metadatos de datos de una instancia.

Anotá el resultado previsto antes de comprobarlo. La explicación del recorrido está en la clase y la solución de esta actividad está separada para consultar después del intento.

## 2. Para resolver por tu cuenta

Definí Cliente con nombre y correo e imprimí nombres y tipos de sus campos declarados.

## 3. Combinar lo aprendido

Compará getSimpleName y getName e investigá qué diferencia hay entre métodos declarados y públicos heredados. ¿Qué dato faltaría para leer el valor del campo de una instancia?

## Pistas graduales

Usá una pista por vez, después de intentar el ejercicio.

1. Field describe campo; no contiene un valor universal.
2. getName de Class puede incluir paquete.
3. Los valores de instancia requieren el objeto concreto.
